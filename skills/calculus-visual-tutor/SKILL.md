# 高数图解教学

以同济第八版的知识范围和条件为准，用普林斯顿的解释方式帮助学生看见公式背后的变化过程。默认中文，一次解决一个主要理解障碍；结合已有对话判断基础，不必先发整套问卷。

## 选内容

- 极限、ε–δ：读 [精读教学设计](references/deep-reading.md) 的极限部分。
- 导数、切线、链式法则：读同一文件的导数部分。
- 积分与微分为什么互逆、变限积分：读同一文件的基本定理部分。
- 其他知识点：沿用下述教学方法，按需查原教材，不声称已经精读。多元微积分、重积分、曲线曲面积分等不能冒充普林斯顿原书覆盖内容。
- 精确核对原文、页码或章节对应时，读 [资料与阅读范围](references/sources.md)。OCR 中的公式须看原页图核对。

## 讲解方法

先定位学生混淆的两个对象，如“函数值与极限”“平均变化率与瞬时变化率”“累积量与累积速度”。选择一个数值简单的例子，把对象放进同一张图中。

每次完整的概念教学必须有至少一幅解释该概念的数学图。图中标记需要讲解的变量、坐标、趋近过程或几何量；正文明确指出哪一处图形对应哪一步公式。不能用装饰插图或知识树代替数学解释图。用户只要简短答案时，按其范围回答。

推荐组织：困惑 → 图与具体例子 → 直观解释 → 定义和条件 → 逐步推导 → 一个变式 → 一个检查理解的小题。允许根据内容合并，避免机械堆小标题。

先说明变量各自扮演什么角色。每个关键等号解释依据；明确标出近似符号与极限过程。直观图只提供理解，不能替代对所有对象成立的证明。先给可理解的结论，再按学生需求增加证明细节。

例题按“识别结构—检查条件—选择方法—计算—检验”展开。误区通过反例纠正，例如项趋于零并不能保证级数收敛。练习应检验迁移，避免只替换数字。学生回复后依据错误调整讲解，不直接归因为粗心。

## 作图

可用 `scripts/draw_calculus.py --topic all --outdir <输出目录>` 生成三组原创 SVG：极限范围、割线趋近切线、累积面积与新增面积。单主题参数为 `limit`、`derivative`、`ftc`。这是固定示例，改题目后必须同步改函数、区间、数值、标签和条件。

曲线图用 SVG、标准绘图工具或准确的交互图，不用生成式图片绘制公式与函数曲线。关系结构可用 Mermaid。需要观察参数变化时可制作滑块或多帧对照，但静态输出必须仍可理解。

展示图片时使用绝对路径 Markdown 图片。SVG 不能显示时导出 PNG；交付前查看实际渲染，检查文字遮挡、坐标、图例和颜色区分。不要只提供未渲染代码。用颜色同时配合标签、线型，图不能靠颜色独立传达结论。

## 数学检查

- 极限：δ 在 ε 给定后选择；控制所有满足条件的 x；排除 x=a。无限极限不与实数极限混写。
- 导数：先让 h≠0 才能除以 h，再取极限；“小”不等于零。切线可以穿过曲线。
- 链式法则：外层导数在内层值处计算。微分符号约分只是助记，解释应来自局部变化率。
- 基本定理：连续性是本 skill 入门版本的充分条件；定积分是带符号累积量。区分变限积分函数、不定积分族和定积分数值。
- 变限积分：连续 f、可导 u,v 时，d/dx ∫[u(x),v(x)] f(t)dt = f(v(x))v′(x)−f(u(x))u′(x)。若被积函数还含外部 x，不能直接套此式。
- 反常积分与断点必须单独处理，不跨奇点机械代入原函数。一般可积函数不一定有原函数。

图形数值、公式、定义条件和题目结果一致后才交付。引用以章节、原书页码为主，使用自己的讲解与原创图，不复制长篇教材内容。
