## 全书的讲解方式

先说明数学对象是什么、为什么需要它，再建立直观图像或现实模型；随后把直观转换成定义或公式，解释为什么选择某种变形，最后用例题及反例检验条件。例题中的“下一步为什么这样做”应作为教学重点，不只列运算步骤。

后续讲解可采用：问题与直观 → 精确含义 → 使用条件 → 方法选择 → 完整例题 → 常见错误 → 独立练习。这个顺序是本次阅读归纳的教学安排，不是原书逐字模板。

## 第1—10章：基础、极限与求导

| 章及印刷页 | 内容与讲解思路 | 教学时必须强调 |
|---|---|---|
| 1 函数、图像和直线，1—20 | 用输入与输出规则解释函数；区分定义域、上域与值域；垂线检验对应函数，水平线检验对应反函数；从操作次序理解复合 | 相同表达式在不同定义域上可表示不同函数；反函数不是倒数；去掉绝对值前需判符号 |
| 2 三角学回顾，21—33 | 从直角三角形推进到单位圆；参考角、象限符号、周期、图像与恒等式相互支撑 | 微积分公式采用弧度；负角和多圈角先化简，再核对象限 |
| 3 极限导论，34—46 | 将“邻近时发生什么”与“该点取什么值”分开；左右极限、无穷远行为和夹逼以图像解释 | 双侧极限需左右相等；无穷不是实数；渐近线可以被曲线穿过 |
| 4 多项式极限，47—62 | 先尝试代入；零比零时约因子或有理化；无穷远时提取主导项；负无穷和绝对值单独判符号 | 零比零不是答案；局部约去公因子不改变邻近行为；平方根内提取平方须带绝对值 |
| 5 连续性和可导性，63—83 | 连续是极限值与实际值相配；由平均速度、割线斜率的极限建立导数；高阶导数连接速度和加速度 | 连续与可导不同；闭区间连续定理需完整条件；速度有方向，速率非负 |
| 6 如何求解微分问题，84—110 | 从定义求导过渡到四则和链式法则；用矩形增量解释乘积法则，用两次局部拉伸解释链式法则；从曲线陡峭程度画导函数 | 乘积不能只对两因子分别求导后相乘；复合函数逐层求导；分段连接点原则上回到差商定义 |
| 7 三角函数极限和导数，111—131 | 按三角函数的内部变量趋向小量、大量或普通值分类；小角匹配重要极限，大量振荡结合有界性与夹逼；单位圆证明重要极限 | 自变量趋于零不等于三角函数内部趋于零；有界振荡可能在衰减因子作用下趋零；可导函数的导数不必连续 |
| 8 隐函数求导和相关变化率，132—147 | 把y看作x的函数，对等式两侧求导；应用题先建立相关量的方程，再对时间求导 | dy/dx与二阶导数不同；数值代入不能提前消灭变量依赖；变化率要有单位与符号 |
| 9 指数函数与对数函数，148—181 | 指数与对数互为逆操作；从复利引入e；区分零、1、无穷附近的极限；通过取对数处理幂指函数；连接增长、衰减和双曲函数 | 对数自变量须为正；ln0无定义；比较增长速度要说明方向；对数求导需考虑表达式符号及定义域 |
| 10 反函数与反三角函数，182—202 | 用单调性解释可逆；通过隐函数求导得到反函数导数；用受限定义域选择反三角函数主值 | 原函数导数为零时反函数可能不可导；反三角函数返回值受主值区间限制；根号符号取决于区间 |

## 第11—21章：导数应用与积分

| 章及印刷页 | 内容与讲解思路 | 教学时必须强调 |
|---|---|---|
| 11 导数和图像，203—219 | 区分局部与全局极值；罗尔与中值定理联系平均变化和瞬时变化；一阶导数判断走向，二阶导数判断弯曲 | 驻点仅是候选点；还需考察不可导点和边界；二阶导数为零不能直接判极值或拐点 |
| 12 函数图像，220—239 | 把定义域、对称性、截距、渐近线和一二阶导数汇总到符号表，再描图 | 符号表分界要覆盖零点及无定义点；样本点只代表同一符号区间；图像计算器不能代替分析 |
| 13 最优化与线性化，240—263 | 优化先定义目标与变量，通过约束化成单变量；线性化是用切线近似；牛顿法由切线交轴得到下一次猜测 | 别遗漏可行域、端点及边界极限；近似不是等式；牛顿法可能走向错误根、循环或发散 |
| 14 洛必达与极限综述，264—276 | 先判断不定式结构；乘积、差和幂指形式转为可使用法则的商；与代数变形、重要极限和主导项方法并列选择 | 不适用时不能求导；分子分母分别求导不是对整个商求导；重复使用前重新检查条件 |
| 15 积分入门，277—294 | 先熟悉求和、叠缩、分区与矩形；从速度分段近似建立位移累积，再令最大分段长度趋零 | 积分的构造不是直接假设“无限小矩形”；路程与带符号位移不同；所有小区间都必须变细 |
| 16 定积分，295—322 | 面积直观转成黎曼和极限；积分是带符号累积的数；通过竖条、横条建立面积；平均值由面积除以区间长度得到 | 面积与定积分不同；积分变量决定上下限；不可积函数存在；函数可积不自动意味着拥有原函数 |
| 17 微积分基本定理，323—348 | 上限移动时增加窄条，面积的变化率是当前高度；原函数端点之差计算定积分；区分定积分、不定积分和积分定义函数 | 变上限求导要配合链式法则；上下限都变化时分开；连续性等条件不可省略；积分常数只属于原函数族 |
| 18 积分方法第一部分，349—373 | 换元反向使用链式法则；分部积分反向使用乘积法则；有理函数积分先除法、分解、定系数，再逐项积分 | 换元须转换所有变量、微分和定积分上下限；分部积分应使新积分更简单或能循环消去；二次因子分子用一次式 |
| 19 积分方法第二部分，374—393 | 三角函数乘积用恒等式和奇偶次数选法；根式按三种平方结构三角代换；用参考三角形换回原变量；最后总结方法选择 | 留出与微分配合的因子；开根号需要区间与符号；不同不相连定义区间可以各有积分常数 |
| 20 反常积分基本概念，394—410 | 不可直接套普通定积分；无界积分区间或被积函数需用单侧极限；收敛、比较、极限比较与绝对收敛以面积说明 | 每个瑕点都要单独处理；正负发散不能相消成普通收敛；比较法方向不能颠倒；绝对值积分发散不代表原积分发散 |
| 21 反常积分解题，411—434 | 先找齐全部瑕点，逐一拆分；无穷远看主导项，零附近看最低阶非零行为；必要时平移瑕点到零 | 渐近关系通常可乘除，不能随意加减；零附近与无穷远的p积分标准相反；需处理被积函数的符号 |

## 第22—30章及附录

| 章及印刷页 | 内容与讲解思路 | 教学时必须强调 |
|---|---|---|
| 22 数列与级数概念，435—456 | 数列极限与部分和极限分开；用走路位置解释级数；几何级数、比较、根值、比值、积分及交错判别各有条件 | 通项趋零只是必要条件；判别收敛不等于求级数和；比值或根值等于1时无法判定；交错判别需最终递减且趋零 |
| 23 级数解题，457—474 | 先检查通项，再依据阶乘、指数、n次幂、幂次或对数选择判别；含符号先考虑绝对收敛 | 不要机械地把比值判别用于所有题；绝对值级数发散后再讨论条件收敛；积分判别需检查正性、连续性及最终单调 |
| 24 泰勒与幂级数导论，475—489 | 从切线到抛物线，再到匹配更多阶导数的多项式；余项衡量近似误差；无穷展开额外需要余项趋零 | 阶与次数不同；幂级数收敛和收敛到原函数是不同问题；不能从“无限可导”直接推出等于泰勒级数 |
| 25 估算问题，490—504 | 选函数、展开中心和所需阶数；先写余项再控制高阶导数；交错展开可用首个舍弃项估误差 | 精度要求决定阶数；需在整段区间内控制导数；交错误差估计仅在相应条件成立时可用 |
| 26 泰勒和幂级数解题，505—525 | 比值或根值求收敛半径，端点另查；基本级数经代换、求导、积分和代数操作得到新级数；最低阶项处理极限 | 指标n趋无穷与变量x趋某点不能混淆；端点不可自动保留；截断后算术操作应控制阶数；所有项抵消可能要多展开几项 |
| 27 参数方程与极坐标，526—540 | 参数是驱动点运动的变量；dy/dx由两种随参数的变化率相除；极坐标用方向和距离描述点；扇形微元建立面积 | 同一曲线可以不同速度、不同次数遍历；极坐标表示不唯一；负半径反向；重描曲线会重复计算面积 |
| 28 复数，541—558 | 从i到复平面；指数形式解释旋转和乘法；多值辐角处理n次根和复指数方程；级数连接欧拉公式 | 求根要列出全部不同根；角度差2π表示同一点；复对数涉及分支，不能无条件照搬实对数规则 |
| 29 体积、弧长和表面积，559—580 | 画典型小条并旋转，决定圆盘、圆环或柱壳；一般截面积积分；弧长来自勾股定理，旋转表面积来自周长乘弧长 | 半径是到旋转轴的距离；dx、dy决定上下限；表面积不是简单的周长乘水平宽；重复遍历需注意 |
| 30 微分方程，581—600 | 可分离变量与积分因子；指数试解导出特征方程；非齐次解由齐次解加特解构成；用初始条件确定常数，再回到实际模型 | 分离时除以未知函数可能丢常数解；反函数主值不能替代所有分支；特解与齐次解重合需乘x；模型通常只在物理允许范围内有效 |
| 附录A，601—632 | ε–δ定义解释为先指定纵向精度、再找横向邻域的应对游戏；扩展到无穷与单侧极限，证明运算、连续、中值与泰勒结论 | 量词顺序不可交换；邻域依赖精度；复合极限有额外条件；本附录包含柯西中值定理在洛必达证明中的使用 |
| 附录B，633—643 | 用矩形、梯形和抛物线逼近面积；导数上界限制误差；通过误差界选择分段数 | 辛普森法需要偶数个等长子区间；公式权重不同；误差界是保证，不等于实际误差 |

## 后续教学需回看原页的地方

1. 第6章分段求导的简便匹配法（印刷p105）附脚注说明：连接点两侧导函数极限存在且有限时，匹配法才可直接使用；一般问题用左右差商定义。
2. 第13章圆柱罐成本例（印刷p245）在成本两端趋于正无穷、二阶导数为正的讨论后，出现“局部最小值和全局最大值”字样；按上下文与数学结论应为全局最小值。教学不能照抄该字样。
3. 第16—17章应明确：连续函数有原函数；一般黎曼可积函数不必有原函数。不能把直观段落中的概括脱离前提使用。
4. 部分段落用ln0或无穷的简写帮助直观理解；正式解答用单侧极限和发散描述。
5. 初步对照表中“柯西中值定理未见专节”需要细化为：正文第11章不设该专节，但附录A.6.13使用并阐述相关中值定理，不应说全书没有。
